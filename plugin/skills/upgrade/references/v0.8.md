# v0.8.0 — convention-gate field fixes (first consumer run)

## Heads-up: C9 ("collections are read-only") is retired

The gate no longer flags `onInsert`/`onUpdate`/`onDelete` on a collection. The house write-model is now official and documented as `/dobby:data-fetching`'s Step 4: persistence handlers CALL the module's server fns — optimistic apply, rollback on throw, default refetch reconcile. If this repo suppressed the old rule or routed writes around collections to satisfy it, those workarounds can be unwound; a handler that writes storage DIRECTLY (a client SDK, a raw `fetch`) is still the shape to reject in review — the gate just can't tell the two apart anymore, so that half is judgment again.

## Heads-up: every tier now has a suppression story

Treat each finding as a fix-vs-suppress call; when suppress wins, the syntax is per tier:

- Native Biome rule: `// biome-ignore lint/<group>/<rule>: <reason>`
- GritQL plugin rule: `// biome-ignore lint/plugin/<grit-file-stem>: <reason>` (e.g. `lint/plugin/c10-collection-not-eager` — the `lint/` prefix is required)
- Filesystem-scanner rules (B1–B10, C2/C3/C12): `// dobby-allow <RULE-ID>: <non-empty reason>` — NEW in 0.8. Anywhere in the judged file for a per-file rule; in the comment run directly above the `createServerFn` chain for C3 (per chain — one blessed public endpoint never covers its neighbour); in the directory's `CONTEXT.md` for B4. An empty reason is not honored, and the full gate counts honored allows in a note.

If the previous jump left findings the repo decided to live with (a deliberately public endpoint, a config file the exception set missed), annotate them now — the gate goes green without an upstream release.

## Action: vendored shadcn can move to `src/shadcn/**` (unblocks the B4 dissolution)

The preset now excludes `src/shadcn/**` (alongside the legacy `src/components/ui/**`) and generalizes the generated-DB-types exclusion to `src/**/database.types.ts`. If this repo carries B4 findings on `src/components`/`src/hooks`/`src/lib`, the sanctioned move is: vendored shadcn code → `src/shadcn/{ui,hooks,utils.ts}` with `components.json` aliases repointed (`"ui": "@/shadcn/ui"` etc.), then dissolve the remaining buckets into feature modules. The moved vendored code stays unlinted — executing the move no longer turns the gate redder.

## Awareness: fewer false positives, no action needed

- B7 exempts `nitro.config.ts` on both layers, and comments are stripped (string-aware) before the env-access match — prose naming `process.env` is not a read.
- B4 fires on the full gate only — the edit hook no longer blocks an edit inside a legacy bucket on the directory's pre-existing debt.
- C12 resolves `db.select(<identifier>)` to its same-file hoisted `const` projection — the hoisted shape gets a real check instead of a skip, and an unrelated literal select can no longer fabricate a mismatch.
- C10's message names the sanctioned memoized per-input collection factory and its suppression.
